## Featured Projects

### URL Shortener with Analytics
URL shortener with click analytics, built to practice Redis fundamentals.
- Short links with configurable **TTL** (`SET`/`GET`)
- Click counter with `INCR` and ranking with **Sorted Sets**
- Caching layer with `@Cacheable` over PostgreSQL
- **Stack:** `Java 17` `Spring Boot` `Redis` `PostgreSQL` `Docker` `Testcontainers`

### Rate Limiter
Request rate limiter based on the **Token Bucket** algorithm.
- Per-client limiting by IP, configurable per route
- Returns `429 Too Many Requests` with a `Retry-After` header
- Storage moving from in-memory to **Redis**
- **Stack:** `Java` `Spring Boot` `Redis` `Testcontainers`

### OneTime Project (TOTP)
Time-based One-Time Password implemented **from scratch**, with no third-party libs for the core logic.
- Secure key generation, Base32, HMAC-SHA1 and dynamic truncation
- Validated against **Google Authenticator**
- Evolving into a CRUD with endpoints protected by TOTP as a second factor
- **Stack:** `Java` `Spring Boot` `Lombok` `MySQL` `Docker`
